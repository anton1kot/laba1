# laba1
## CLI‑утилита: калькулятор выражений и конвертер единиц массы.

## Возможности

- `calc` — вычисление арифметических выражений (поддерживаются `+`, `-`, `*`, `/`).
- `convert` — конвертация массы (`g`, `kg`),
              длины (`km`, `m`, `cm`,`mm`) и температуры (`C`, `F`, `K`).

## Требования

- Python ≥ 3.12

## Установка и запуск

Из корня проекта:

```
pip install -e .
```

Запуск команд:
```
python -m toolkit calc "1+1"
python -m toolkit convert "10 --from g --to kg"
```
Справка:

```
python -m toolkit --help
```

Тесты
```
python -m pytest 
```

Проверка
```
ruff check .
```

Структура проекта

## Особенности реализации
- Вычисление стеком через обратную польскую запись
- Вычислительное ядро (функции calc, convert) не использует input/print.
- Вывод ошибок в stderr и завершение с кодом 2 и успешное завершение с кодом 0
- Обработны ошибки:
  - Пустое выражение
  - недопустимый символ
  - пропущенный операнд
  - пропущенный оператор
  - два бинарных оператора подряд
  - деление на ноль
  - неизвестная единица измерения
  - конвертация несовместимых единиц
  - неверное числовое значение
